# MyFitness
부위별 운동 기록 + 목표 달성률 웹앱 (초안). 정적 파일만으로 동작하고 데이터는 브라우저 localStorage에 저장돼요.

- 부위(그림/목록)를 누르면 기록 팝업, 상단 `＋ 운동추가`로도 기록
- 종목 분모 = 목표일수 × 회 × 세트 / 분자 = 기록(회 × 세트) 누적 (초과달성 가능, 100% 넘으면 금색)
- 부위 % = 부위 내 분자합 / 분모합, 전체 % = 전 종목 분자합 / 분모합
- 옵션: 목표일수/주당일수/기준 회·세트 설정, 부위별 종목 추가·삭제, JSON 백업/복원

로컬 확인: `python3 -m http.server 8080` 후 접속. 배포: GitHub Pages (mzmzkgu.github.io/MyFitness).
