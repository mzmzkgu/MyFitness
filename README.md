# MyFitness
부위별 운동 기록 + 월간 목표 달성률 웹앱. 정적 파일만으로 동작하고 데이터는 브라우저 localStorage에 저장돼요.

- 3D 인체(Three.js, 드래그로 회전 · 앞/옆/뒤 버튼): 데생 마네킹(기본, three.js 예제의 Mixamo X Bot glTF를 CDN에서 로드 → 뼈대/위치로 부위 자동 분류) / 귀여운 캐릭터(도형 조립) — 옵션에서 전환 — WebGL이 안 되면 2D 그림으로 자동 대체
- 부위(그림/목록)를 누르면 기록 팝업, 상단 `운동추가`로도 기록
- 종목 분모 = 월 목표일수 × 회 × 세트 / 분자 = 해당 월 기록(회 × 세트) 누적 → 매월 1일 0부터 다시 시작 (지난 달 기록은 보존, 달력에서 월을 넘기면 그 달 성적 확인)
- 부위 % = 부위 내 분자합 / 분모합, 전체 % = 전 종목 분자합 / 분모합 (초과달성 가능, 100% 넘으면 금색)
- 달력 헤더: `목표 달성일/월 목표일수 · 달성률` (월별)
- 옵션: 월 목표일수/주당 일수/기준 회·세트 설정, 부위별 종목 추가·삭제, JSON 백업/복원
- v1(누적 목표일수) 데이터는 자동으로 월 목표(주당 일수 × 4)로 마이그레이션

로컬 확인: `python3 -m http.server 8080` (3D 모듈은 file:// 로는 안 불러와지니 http로 열 것). 배포: GitHub Pages (mzmzkgu.github.io/MyFitness).
